IoT telemetry POST /api/integrations/iot/telemetry

One reading or a list (max 5 000). Unknown machines are registered automatically. Timestamps default to now (UTC).

curl -X POST {{ origin }}/api/integrations/iot/telemetry \
  -H "X-API-Key: {{ key }}" -H "Content-Type: application/json" \
  -d '{{ '{' }}"machine_id":"L03-PRS-01","ts":"2026-10-12T08:00:00Z","temperature_c":71.2,"vibration_mm_s":4.4,"current_a":16.1{{ '}' }}'

Machine events POST /api/integrations/iot/events

-d '{{ '{' }}"machine_id":"L03-PRS-01","event_type":"failure","description":"Hydraulic seal"{{ '}' }}'

Google Cloud Pub/Sub push POST /api/integrations/pubsub/push?token=… {{ data?.pubsub_configured ? 'configured' : 'not configured' }}

Create a push subscription pointing here. message.data = base64 JSON telemetry (or a list); attribute type=event for events. Set PUBSUB_VERIFICATION_TOKEN on the service.

gcloud pubsub subscriptions create sf-telemetry-push --topic=factory-telemetry \
  --push-endpoint="{{ origin }}/api/integrations/pubsub/push?token=$PUBSUB_VERIFICATION_TOKEN"
